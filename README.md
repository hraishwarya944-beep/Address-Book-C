# Address Book – Contact Management System

## 📌 Project Overview

Address Book is a console-based, menu-driven application developed using C programming.

The project is used to manage contact information such as name, phone number, and email. It allows the user to create, search, edit, delete, and list contacts.

The contact details are stored in a file so that the data can be retained even after the program is closed.

## 🎯 Aim

To develop a simple contact management system using C programming concepts such as structures, functions, file handling, and modular programming.

I developed this project to strengthen my C programming skills and understand how real-world data can be stored and managed using structures and files.

## ⚙️ Features

### 1. Create Contact

Allows the user to add a new contact by entering:

- Name
- Phone Number
- Email

### 2. Search Contact

Allows the user to search for an existing contact.

### 3. Edit Contact

Allows the user to modify the details of an existing contact.

### 4. Delete Contact

Allows the user to delete an existing contact.

### 5. List Contacts

Displays all the contacts stored in the Address Book.

### 6. File Storage

Contact details are stored in a file so that the data is available even after restarting the program.

## 🧠 Working Principle

1. The program starts and loads the existing contact information.
2. A menu is displayed to the user.
3. The user selects an operation.
4. Based on the selection, the program performs Create, Search, Edit, Delete, or List operation.
5. Updated contact information is stored in the file.
6. The user can continue performing operations until choosing to exit.
